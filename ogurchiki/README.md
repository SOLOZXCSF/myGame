# Swing Game (JDK 22, Maven)

Запуск:   mvn compile exec:java
Сборка:   mvn package && java -jar target/swing-game-1.0-SNAPSHOT.jar

Мультиплеер на одном компьютере (localhost):
1. Запустите игру, нажмите «СОЗДАТЬ ХОСТ».
2. Запустите вторую копию игры, оставьте адрес localhost и порт 5000, нажмите «ПОДКЛЮЧИТЬСЯ».
   (Для игры по сети вместо localhost укажите IP хоста.)

Управление: WASD или стрелки, Esc — выход в меню.
