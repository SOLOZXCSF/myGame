# Swing Game — Multiplayer Shooter (JDK 22, Maven)

## Запуск
```
mvn compile exec:java
```
или собрать fat-jar:
```
mvn package && java -jar target/swing-game-1.0-SNAPSHOT.jar
```

## Мультиплеер (localhost)
1. Запустите первую копию → **СОЗДАТЬ ХОСТ** (порт 5000)
2. Запустите вторую копию → **ПОДКЛЮЧИТЬСЯ** (адрес `localhost`, порт 5000)
3. По сети: вместо `localhost` укажите IP-адрес хоста.

## Управление
| Клавиши | Действие |
|---------|----------|
| WASD / стрелки | Движение |
| **Пробел** | Стрельба в сторону движения |
| Esc | Выход в меню |

## Механика
* У каждого игрока **3 ХП** (сердечки под персонажем).
* Попадание пулей снимает 1 ХП; при потере всех — игрок **возрождается** с полными HP.
* Пуля летит в направлении последнего движения; стрельба кулдаун 0.35 с.
* Вся физика (движение, стрельба, коллизии) считается только на хосте.
  Клиент получает позиции и пули готовыми и только рисует их.
